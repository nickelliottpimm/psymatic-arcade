Psymatic Arcade launchers. Double-click a .command file to start a game.

Before playing on the wall: set the external display to 1280x720 or
1920x1080 (16:9) in System Settings > Displays.

Fullscreen: Mario Kart F11, GoldenEye F11, Perfect Dark / GE-X Alt+Enter.
All four are set to stretch 4:3 to fill the 16:9 output.
