# Playtest notes

Vanilla observations only. What feels wrong, missing or improvable.
Format: date, game, build/version, machine, observation.


- 2026-10-18, GoldenEye X 6a on Dab's Mod v3.14.0 (+Stretch43, Video.Display=1),
  M1 laptop, 2x N64-style USB pads: Virtual Reality multiplayer starts and
  runs with 4 players. With ExtendedControls=0 (style 1.1) the user reports
  it working. Main menu reads "OHMSS Directory"; MP is "Virtual Reality".

- 2026-10-18, all games, user summary after a full test session:
  - Testing successful across all four games.
  - Pads time out after a few minutes idle. They re-pair on button press,
    but often come back as a different player (pad 1 rejoins as player 2).
    Needs understanding for long exhibition runs.
  - GoldenEye X is the better GoldenEye for the wall (bot options). Keep
    GoldenEye Native for purists.
  - Mario Kart 64 was very entertaining.
  - Launching and quitting games is clunky. Navigating each game's own
    opening menus is too fiddly for a public exhibition.
